A marca do Dockd é o wordmark `dockd.` composto em texto, Archivo 900 a 125% de largura, com o ponto em `red`. Não há arquivo de wordmark: é sempre tipografia viva, para acompanhar o tema. O símbolo aqui é uma proposta para favicon e ícone de app: a silhueta 3:4 de uma capa em `ink` com o ponto `red`. Uma versão por tema porque `<img>` não herda cor; use `dockd-mark-light.svg` sobre `surface` clara e `dockd-mark-dark.svg` sobre `surface` escura.
