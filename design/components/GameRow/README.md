# GameRow
Linha de lista para a fila de compra, para as versões na página do jogo e para lançamentos. Coluna esquerda de `thumb-height`: miniatura de capa ou DateBlock, nunca os dois. No meio, título `t-heading` numa linha e `t-meta` com plataforma, mídia e ano separados por ponto mediano. À direita, uma coisa só: um Price, um StatusChip ou um Button secundário pequeno. Todas as linhas de uma lista têm a mesma altura.

Separada da próxima por um fio `line`; sem fundo, sem borda lateral, sem botão primário. Uma linha é um link inteiro quando leva à página do jogo; quando tem botão, só o botão é interativo. O consumidor fornece título, capa ou data, metadado e o que vai à direita.
