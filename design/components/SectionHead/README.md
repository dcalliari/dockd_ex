# SectionHead
Título de seção em `t-label` `ink-muted` sobre um fio `line`, com contagem opcional em `t-meta` e um link `red-ink` à direita: `PRÓXIMOS LANÇAMENTOS 4 · Ver todos`. É o padrão do Letterboxd e o único título que existe dentro de uma página.

Não use para o nome da tela, que já está na NavBar. O consumidor fornece título, contagem e ação. Duas seções seguidas separam-se por `space-6`.
