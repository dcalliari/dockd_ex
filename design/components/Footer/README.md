# Footer
Uma linha só no fim de toda tela, em `t-meta` `ink-muted` sobre um fio `line`, na largura do conteúdo: o wordmark pequeno, `Sobre` e `Dados de jogos por IGDB`, separados por ponto mediano. `IGDB` é link sublinhado para igdb.com; `Sobre` leva a `/sobre`. Sem ícone, sem coluna, sem rede social.

Termos e Privacidade entram nesta mesma linha só quando o Dockd abrir para outras pessoas. Entrar e Criar conta não têm rodapé: as capas cobrem a tela. No celular, com a barra inferior, o rodapé reserva `nav-height` mais `space-5` embaixo para terminar acima dela, nunca sob ela. O consumidor não fornece nada; o crédito de cada dado do IGDB na página do jogo e na busca continua onde está.
