Configurações de conta · a decidir

O que hoje já é configurável, e o que seria novo

Não existe uma tela única de conta hoje: privacidade do perfil já se edita em /u/:nome, e o resto (e-mail, senha, nome de usuário, exclusão) não tem UI nenhuma. A lista abaixo é o conteúdo que proponho para Configurações; marquei o que reaproveita algo que já existe e o que é novo.

  • Perfil — nome de exibição novo (hoje vem só do e-mail, sem edição), nome de usuário novo (hoje gerado uma vez; trocar muda o link do perfil), privacidade do perfil já existe (mesmo Choice de /u/:nome, reaproveitado, não duplicado).
  • Conta — e-mail novo (sem changeset de troca hoje; exige confirmar dentro da tela), senha tela nova (a troca já existe no domínio, só falta a UI), token da API já existe no menu — mantenho lá, para não duplicar a ação.
  • Encerrar — excluir conta novo (não existe função nem UI hoje); confirma no próprio controle, sem confirm(). Sair já existe no menu e não entra aqui, para não repetir a ação.
  • Fora da proposta: avatar (o design system veta foto e iniciais no perfil), preferência padrão de plataforma ou mídia (hoje é por jogo, não por conta; nada pede isso ainda) e lista de sessões ativas (o modelo é de sessão única, Sair já cobre).

Onde é acessada

Um item novo, Configurações, entra no menu da conta logo depois de Perfil, antes de Conferir catálogo e Sair. O menu é o mesmo componente (account_menu/1) em toda tela.

Opção A · seções numa página só recomendado

Perfil, Conta e Encerrar como três SectionHead na mesma rolagem, no padrão que a página do jogo e Comprar já usam. Sem clique extra para trocar de grupo; cada campo edita no próprio lugar, como o preço em Comprar.

Opção B · abas

Perfil, Conta e Encerrar como abas, no componente Tabs que a Biblioteca já usa. Separa mais os grupos, mas cada troca de aba é um clique a mais do que rolar a página inteira.

Opção C · lista lateral

No desktop, uma coluna à esquerda como painel de sistema. No celular não cabe coluna: vira uma lista de três linhas, e cada uma abre uma subtela própria, com Voltar. É a opção com mais cliques no celular, por isso não é a recomendada.

Minha recomendação

Opção A, seções numa página só. É a que pede menos clique: no celular, que é onde a lista lateral (C) piora mais, A só pede rolar. As abas (B) protegem contra uma página comprida, mas Configurações tem só sete campos ao todo, pouco para justificar um clique a mais por grupo. A confirma dentro do próprio controle, sem confirm() nem página nova, tanto para trocar e-mail quanto para excluir a conta, como o `Desfazer` já faz em Comprar e no StatusMenu.
